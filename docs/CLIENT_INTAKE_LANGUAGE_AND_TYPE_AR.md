# مراجعة الخط والوضوح وتبديل لغة صفحة الطلب

## الخط والأحجام

اعتمدت صفحة الطلب IBM Plex Sans Arabic للعربية وOutfit للإنجليزية. الخطان محليان داخل المشروع، مع أوزان عربية أصلية 400 و500 و600 وتضمين ترخيص OFL. لم تُعدّل هندسة الشعار أو خط كلمته.

- النصوص والحقول والأزرار: 16 بكسل، مع ارتفاع سطر مريح.
- النص المساعد والعناوين التوضيحية الصغيرة: 14 بكسل بدل 10–12.
- العنوان الرئيسي: 28 إلى 36 بكسل بحسب العرض؛ عنوان القسم 22 بكسل.
- قياسات الخط تستعمل rem، والحقول النصية بارتفاع أدنى 48 بكسل والأزرار 44 بكسل.

أزيل اعتماد الخط العربي على تحميل Google Fonts وقت الزيارة. مصدر الملفات غير المعدلة: [Google Fonts / IBM Plex Sans Arabic](https://github.com/google/fonts/tree/main/ofl/ibmplexsansarabic). دليل العائلة: [IBM Typeface](https://www.ibm.com/design/language/typography/typeface/).

## الألوان والتباين

الهوية الكحلي والسماوي مناسبة لصفحة الخدمة. المشكلة التي عولجت هي تطبيق لون النص المساعد الغامق على شرح داخل خلفية كحلي. أصبح شرح المقدمة #CBD5E1، مع بقاء لون النص المساعد الغامق على المساحات الفاتحة.

قياسات التباين الحسابية للأزواج المستخدمة في الصفحة:

| النص / الخلفية | النسبة |
| --- | --- |
| النص الأساسي / الأبيض | 18.38:1 |
| الشرح / الأبيض | 6.05:1 |
| الشرح / خلفية الصفحة | 5.38:1 |
| شرح المقدمة / الكحلي | 12.38:1 |
| كتابة الزر البيضاء / الكحلي | 18.38:1 |
| علامة الاختيار المقترح / الأبيض | 5.39:1 |

هذه الأزواج تتجاوز حد النص العادي 4.5:1 في [شرح W3C للتباين](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html). هذه مراجعة للأزواج المقاسة، وليست شهادة مطابقة شاملة للموقع.

## العربي والإنجليزي

- زر التبديل ظاهر في رأس صفحة الطلب، مع حفظ اختيار اللغة محليًا.
- يتغير lang وdir للصفحة والعنوان في المتصفح، مع RTL للعربية وLTR للإنجليزية.
- الترجمة تشمل المسار السريع والتفصيلي، الدول، الاختيارات، الحقول الإضافية، الموافقة، المراجعة، النجاح، أخطاء الخادم المعروضة، رسائل تحقق الحقول، رأس الصفحة وتذييلها ونافذة دخول الفريق عند فتحها من الصفحة العامة.
- تتغير المحاذاة والأسهم والمسافات بحسب الاتجاه. تبقى الهواتف وأكواد الدول والمعرفات في اتجاهها الصحيح، وتُعزل نطاقات الميزانية الرقمية لمنع انعكاس ترتيبها.
- البيانات التي كتبها العميل وأسماء ملفاته لا تُترجم ولا تُمسح عند التبديل. تظل معرفات الخدمات وقيم اختياراتها الأصلية ثابتة، وتُترجم أسماء العرض فقط. تُسجل preferredLanguage مع الطلب.
- تُغلق التنبيهات السابقة عند تبديل اللغة حتى لا يبقى تنبيه باللغة القديمة، وتظل الأخطاء داخل النموذج قابلة للعرض باللغة الجديدة.
- زر اللغة يعرض اسم اللغة الهدف، ويظل اسم العلامة وأكواد العملات والبيانات التي أدخلها العميل كما هي.

## كتالوج الخدمات

تدعم /api/public/services?lang=ar و?lang=en عرضًا محليًا مع الحفاظ على نفس المعرفات وقيم الإجابات. كتالوج المشروع الحالي، بأقسامه الأربعة وخدماته الخمس، له أسماء ووصف عربي وإنجليزي واضحان. لا يتغير سلوك المسار القديم عند عدم إرسال lang، حفاظًا على الصفحات الداخلية.

يمكن تخصيص بيانات إضافية عبر nameAr/nameEn وdescriptionAr/descriptionEn، وأسئلة الخدمات عبر labelAr/labelEn وplaceholderAr/placeholderEn وoptionLabelsAr/optionLabelsEn. الخدمات المضافة مستقبلًا تحتاج نسخة إنجليزية دقيقة؛ البيانات التي ليس لها ترجمة تُعرض بعناوين عامة محلية بدل خلط اللغتين أو اختلاق ترجمة لتخصص غير معروف.

## التحقق

- نجح بناء الواجهة والخادم ونجحت اختبارات الخادم الـ54.
- جُرب الإرسال السريع والتفصيلي بالإنجليزية، والتحقق الإجباري وخطأ رقم الهاتف ورسالة النجاح.
- جُرب تغيير اللغة أثناء وجود خطأ ومع إجابات رقمية واختيار خدمة ومواعيد، ثم التحقق من حفظ القيم الأصلية في قاعدة معاينة مؤقتة.
- فُحص النص الإنجليزي في جميع مراحل المسار التفصيلي دون ظهور نص عربي تابع للواجهة، باستثناء زر اختيار العربية.
- فُحص التذكّر بعد إعادة التحميل، والموبايل بعرضي 320 و390 بكسل، واتجاه الصفحة دون تجاوز أفقي للعناصر القابلة للتفاعل.
- ملفات المعاينة في docs/intake-bilingual/، وبيانات الاختبار لم تُضف إلى قاعدة المشروع الحالية.
